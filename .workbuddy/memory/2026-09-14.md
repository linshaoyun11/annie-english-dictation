## 豆包短语/句子音频响度归一（build 111）
- 用户报昨日豆包音频比单词旧音频小声。实测（活跃语音段 RMS，50ms 帧能量均值）：
  单词美 -13.47 / 英 -15.01 dBFS（对照 400 词抽样）；豆包美 -20.75（差 7.3dB）、
  英 -28.12（差 13.1dB，Stokie 音色输出本身就低）。
- 修复（不重新生成，解码→增益→lameenc 重编码 64kbps/24kHz/mono）：
  每文件 gain = 目标 − 实测RMS，cap +16dB，峰值保护 cap −1.0dBFS（防削波，
  2542/3956 触发峰值约束——全局增益必削波，逐文件是唯一正确做法）。
  管线纯 Python：miniaudio 解码 + numpy 增益 + lameenc 编码（ffmpeg-static npm
  下载 12 分钟超时放弃；pip wheel 秒装，更可靠）。脚本 .workbuddy/tmp/
  {measure_loudness,normalize_loudness}.py。
- 终态：美 median −14.95 / 英 −15.95 dBFS（峰值约束文件略低于目标属正常，
  P10–P90 从 6–13dB 散布收敛到 ~3dB）；全量峰值 ≤ −1.01dBFS 零削波；
  3956/3956 零失败；时长保持（LAME 编码器延迟填充 ≤96ms，无感知）。
- 热点文件（终态峰值 > −1dBFS 31 个）从 git 恢复原始后加 1.5dB 余量重编码，
  避免二次有损转码。
- ⚠️ 今后任何 TTS 换音色/音源，必须做响度对齐（对照组=单词音频活跃RMS中位），
  英音 Stokie 增益需求远大于美音 Dacey。

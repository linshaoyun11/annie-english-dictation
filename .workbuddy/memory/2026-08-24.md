### 本地 git 坑（2026-08-23 深夜发现）
- `.git/refs/remotes/origin/main` 会被某进程反复清空，导致 `git status` 显示 `[gone]`；fetch 报 "[new branch] main -> origin/main" 但引用未持久化。修复：手动 `mkdir -p .git/refs/remotes/origin && git rev-parse HEAD > .git/refs/remotes/origin/main`。仅影响本地显示，远程仓库内容完整（用 git ls-remote 验证）。

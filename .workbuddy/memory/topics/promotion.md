## 核心原则：先修产品，再推广

**推广的终点是商店页。** 商店页有短板时，所有渠道的流量都会漏掉。2026-09-25 实测出四个：

| 短板 | 实测依据 | 影响 |
|---|---|---|
| **无评分引导** | `grep requestReview` 全项目无命中 | 评分既是**排名因子**也是**转化因子**，0 评分两头吃亏 |
| **无分享入口** | `grep navigator.share` 无命中 | 免费 App 唯一的零成本裂变路径被堵死 |
| **商店页「语言」显示 `EN 英语`** | 商店页 + `languageCodesISO2A=["EN"]` | 中文界面标英语，家长会怀疑「这是英文 App 吗」；也影响 Apple 对中文关键词的语义处理 |
| **线上截图缺 1 张** | 线上 7 张 / 本地 8 张，缺 `02-learn.png` | 少的是最能说明产品价值的那张（听写输入界面） |

⇒ 四条**合并进 v1.0.1 一次发出**。理由：改元数据会**重置搜索索引窗口（1-3 周）**，
分次改等于反复推倒重来。而现在通用词还没建立排名，**正是重置成本最低的时刻**。

## Apple 生态内两个免费高杠杆渠道（最容易被忽略）

| 渠道 | 入口 | 关键规则 |
|---|---|---|
| **精选提名**（Featuring Nominations） | ASC → App → 侧边栏「精选」→「提名」→「创建提名」 | 提前 **≥3 周**（想跨多个版面被考虑可提前 3 个月）；编辑**人工挑选**，与算法排名相互独立，不影响关键词排名 |
| **App 内活动**（In-App Events） | ASC → 该版本 → App 内活动 | **活动标题与描述本身参与关键词索引**（= 100 字符关键词之外的额外索引位）；每年 2-4 次，过度使用稀释效果；必须真实有时效，常驻型会被拒 |

两者都是 **¥0**，且绝大多数独立开发者从没做过。教育类是 Apple 编辑的常设主题 ⇒ 值得赌。
**曝光抓手：按教学节奏排期**（期中 / 期末 / 开学），别按自己的开发节奏。

## ⚠️ 付费渠道：个人开发者实际只有一条路

| 渠道 | 个人能否用 |
|---|---|
| **Apple Search Ads** | ✅ 用 Apple ID 直接开通，无需企业主体 |
| 小红书聚光 / 抖音千川 | ❌ 商业投放要企业号 + 资质，教育类还是定向邀约类目 |

**ASA 对免费 App 的清醒判断**：没有内购、没有订阅 ⇒ **投放是纯支出，无直接回收**。
建议只投**品牌词 + 少量品类词**，日预算压到很低（¥30-50），跑 1-2 周看数据；
当作"买初始用户和评分"的手段，不是 ROI 生意。**必须设硬预算上限**
（Apple 允许超支，实际月花费 ≈ 日预算 × 30.4）。

## 小红书（主战场）的四条红线

家长第一聚集地，且教育类内容以**搜索流量**为主（家长主动搜）。但导流管得极严：

1. **站外导流零容忍** —— 2026 年已升级语义追踪，微信/手机号/「私我」/变形字/图片水印/二维码**全部纳入检测**。
   ⇒ **笔记里只能写「App Store 搜索：安妮英语听写」，绝不能出现任何联系方式。**
2. **不得效果承诺** —— 「提分」「逆袭」「保过」「暴涨」都违规，且涉未成年人隐私。
3. **AI 辅助内容必须勾选标注** —— 漏标单篇限流 7 天、账号扣分。
4. **不刷数据** —— 买赞买粉 = 永久限流。

> 👉 正因为不能导流，**ASO 必须先做好**：小红书流量最终靠用户自己去商店搜。**搜不到 = 白推。**

## 对外统一话术（所有渠道只用这一组）

> **6 套教材同步（人教版 / 外研社 / 沪教牛津 / 科普仁爱版，含一三起点）· 654 个单元 ·
> 6108 个词条 · 美音英音双口音 · 完全免费 · 无广告 · 无内购 · 无需注册 ·
> 不收集任何个人信息 · 全部离线可用**

差异点在于「零收费 + 零收集 + 零联网」—— 主流竞品普遍有免费额度上限或订阅墙。
⚠️ 但措辞避开「培训班 / 课程 / 提分」（涉学科培训监管）；
数字统一用去重后的口径，重跑 `node scripts/aso_stats.mjs` 可得。

## 每两周跑一次（判断有没有长进）

```bash
node scripts/verify_live.mjs cn --search 英语听写 --search 单词听写 --search 英语默写
```

看两个数：**通用词有没有进前 50**、**有没有评分出现**。这两个数动了，才说明推广有效果。

**当前基线（2026-09-25，上架当天 4 小时）**：全名 ✅ 第 1 位；通用词全部 ❌ 未收录；无评分。

**关键技术点（踩坑预防，已写入文档）：**
- Windows 上不要跑 `npx cap sync ios`——会把 Package.swift 路径写成 Windows 格式，云端 Mac 不认；iOS sync 必须由 CI 执行。
- 云 CI 打包要求 `public/audio/`（114MB）随 Git 仓库提交（单文件均 <100MB，GitHub 允许）；`ios/` 保持 ignore，CI 现场生成。
- Codemagic 免费额度 500 分钟/月，一次构建约 15-25 分钟。
- 图标 1024 PNG 需无 alpha 通道，如有需压平背景。

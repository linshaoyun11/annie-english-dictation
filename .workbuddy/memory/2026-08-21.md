## Codemagic 构建签名问题修复

用户在 Codemagic 首次构建时遇到报错：No matching profiles found for bundle identifier "com.annie.dictation" and distribution type "app_store"。

**根因：**`environment.ios_signing` 自动签名配置只会在 Apple 端查找已存在的 App Store 描述文件，不会主动创建；新 App 刚注册时往往没有现成的描述文件。

**修复：**将签名方式改为显式脚本调用 Codemagic CLI：
- 移除 `environment.ios_signing` 配置；
- 新增 `BUNDLE_ID: com.annie.dictation` 环境变量；
- 新增脚本：`keychain initialize` → `app-store-connect fetch-signing-files "$BUNDLE_ID" --type IOS_APP_STORE --create` → `keychain add-certificates` → `xcode-project use-profiles`；
- publishing 改为直接读取 Codemagic 注入的环境变量 `APP_STORE_CONNECT_PRIVATE_KEY` / `APP_STORE_CONNECT_KEY_IDENTIFIER` / `APP_STORE_CONNECT_ISSUER_ID`，避免依赖 `auth: integration` 触发方式。

**新增提交：**d50d1f4 fix: use explicit automatic signing with --create for iOS profile。已推送至 GitHub main。

**验证：**YAML 语法经 pyyaml 校验通过；scripts 列表包含全部 10 个步骤；publishing 引用了三个必要变量。

**后续：**用户需重新在 Codemagic 触发 Start new build，构建流程即可用 `--create` 参数按需创建签名证书与描述文件。

## App 端音频缺口 = manifest 未命中（不是文件级 audit）— 2026-09-07 大修正

**用户提醒后大修正**：评估音频缺口必须从 App 端**实际播放路径**出发，
不是看「id 是否有 mp3」。

App 逻辑（`src/lib/audio.ts`）：
```
manifest.get(text.toLowerCase()) → id → public/audio/{id}.mp3
```
- manifest 是**全局唯一**的 text → id 映射（一文本一 id，跨教材共享）
- 同英文词在不同教材里天然走同一段录音（manifest 已指到一个 id）
- 所以「仁爱某 id 没 mp3」不等于「App 漏播」

## 提示面板显示英文答案 BUG 修复（build 81）

### 现象与根因
- 外研一线（waiyansheSL）学习页点「查看提示」直接显示英文单词本身（如 "ancient"），不是音标+译文。
- 根因是**数据问题**而非渲染逻辑：SL 两条线大量词条 `w(g,u,"ancient","","ancient")` —— phonetic 空、chinese 填了英文本身。
- 规模：waiyansheSL 1218 条、oxfordSL 1065 条（共 2283）；其余 5 条线 0 问题
  （oxford 3 条、renai 33 条 badPhonetic 是句子/短语，本来无音标，渲染跳过，正常）。

### 修复方式（自动回填 + 义项级合并）
- 脚本 `.workbuddy/tmp/fix-sl.mjs`：建来源词典（grades4to9/renjiaoSL/waiyanshe/oxford/renai
  + wySL/oxSL 自身好条目 + kebiaoBank + 手工兜底词典 manual-dict.json 289 词），
  按 english（小写 key）回填音标；释义**按词性分组、义项级去重合并**——满足
  「多义词显示所有含义」。2283 条全修复，0 缺失。
- 释义合并关键：复合词性释义（"v. 想知道 n. 奇观"）要按词性标记切成义项序列，
  义项再按 ；切分去重；丢弃纯标点碎片；输出词性标签去掉多余句号。
- manual-dict.json 是我手写的兜底（数字/星期/基础词/短语/专名，其他线没有这些低年级词）。

### 校验（全过）
- 重扫：badChinese 两线归零；tsc 通过；无引号转义问题。
- **g/u/english 三元组 diff 前后完全一致** → entry id 不变、音频 key（文本哈希）不变
  → 不需要重生成音频、不需要升 CURRICULUM_VERSION、用户进度无损。
- APP_BUILD 80→81。

### 踩坑（脚本层面）
- while 条件里 `new RegExp(...).exec(s)` 每次迭代新建正则 → lastIndex 归零 → 死循环
  （跑了 7 分钟才发现）。正则必须在循环外建一次。
- mk() 行的捕获组从 en 开始（m[1]=en m[2]=ph m[3]=cn），与 w()（m[1]=g m[2]=u，
  STR 从 m[3] 开始）不同，第一次就错在这里导致好线数据全没收上。

## 长会话越来越卡（键盘输入/跳题延迟严重）排查与修复（本地完成未推送）
- 排查结论：React 层（监听器清理、状态、localStorage 写入、渲染量）全部干净无泄漏；根因是 **iOS WKWebView 媒体实例累积**——
  1. 主因：`useSpeechLoop` 循环朗读每轮（每 ~3s）都 `releaseElement(旧) + createAudioElement(新)`。一道题停留 60s ≈ 15 次元素销毁重建；长会话数百次。每个 media 元素都分配原生解码器/播放器实例且回收滞后 → 内存压力持续增大 → 整机（键盘事件/渲染/跳题）迟钝。与历史"48 份解码缓冲逼近内存上限卡死"同类。
  2. 次因：每题 `primeSpeech()` new 一个用完即弃的静音 `Audio`，从不释放，每题叠一个媒体实例。
- 修复（`src/hooks/useSpeechLoop.ts`，方案 A'）：
  - `playViaElement(gen, item, forceFresh)`：同一词条循环重播**复用当前元素**（`currentTime=0` 归零重播、不清缓冲——load() 会丢弃已解码数据回退首遍音量偏小）；复用条件 = 同 src(getAttribute 对比) + error===null + (ended||paused)；换词条/后台恢复/播放失败重试仍新建。常驻解码缓冲恒为 1 份。
  - 看门狗检测到卡死时 `playCurrent(gen, true)` 强制换新元素——僵尸元素 play() 不报错但无声，复用会死循环。
  - `advance()` 的 260ms 定时器纳入 timerRef 管理（原来句柄丢弃无法取消）。
  - `speakWebSpeech()` 兜底切换前先 release 遗留音频元素。
  - `primeSpeech()`：静音解锁元素改为模块级 `primeEl` 全局复用（重播归零），不再每次 new。
- tsc 通过；dev 服务器热更新验证可交互。**已提交推送，commit c643225，APP_BUILD 45→46**。真机验证方式：连续学 20~30 分钟对比键盘输入与跳题是否仍越学越迟钝。

## order 无声 + 冷启动键盘残留 BUG 修复（build 44 待发）
- 用户反馈：① APP 冷启动首次进入学习页默认键盘偶发非英文小写全键盘；② 进入 waiyanshe 6年级6单元「At the restaurant」第 3 词 order 无声，切后台几次才有声音，过后几个词条有卡顿（截图 3/10 order）。
- 排查与根因：
  1. **order 无声 / 切后台几次才有声**：`audio.ts` 的 `prefetchAudio` 用 `new Audio()` 创建临时元素预热（建后 canplaythrough 释放），与当前播放的新建 `<audio>` 元素**争抢 WKWebView 媒体并发加载限额**（iOS 已知 6 个上限），导致 play() 落在坏窗口偶发无声/卡顿。切后台几次后才恢复是因为 visibilitychange 触发 stopAll+延迟 350ms 重播（rebuild 元素），期间媒体资源被释放再重分配。
  2. **冷启动默认键盘非英文**：之前的"blur→延迟 200ms→重建 input"加固仅覆盖后台唤醒场景（visibilitychange 触发）。冷启动首屏路径（首页→开始学习→LearnPage→LearningCard→SpellingInput 挂载）走 ref callback + useLayoutEffect + useEffect focus 三道保险仍偶发——iOS 18+ 在 commit 阶段对 input 元素"焊死"一次 keyboard 评估快照（基于插入瞬间属性），后续 useLayoutEffect 设置的 inputmode 不会重评。
- 修复：
  1. `src/lib/audio.ts`：`prefetchAudio` 改用 `fetch(r.url, { cache: "force-cache" })` 仅预热 HTTP 媒体缓存层，不创建临时 `<audio>` 元素。切题时 `createAudioElement` 新建元素从 WKWebView 媒体缓存解码，零资源争抢。
  2. `src/components/SpellingInput.tsx`：useLayoutEffect 中设完 inputmode 后立即 `el.blur()` 让 iOS 丢弃快照，再双 rAF 后 `el.focus()` 触发**新一轮** keyboard 评估（此时 inputmode=latin 已生效）。`done`/`revealed`/可见性任一条件不满足时放弃重评。
- 验证：tsc exit 0；dev 热更新。
- 状态：**已提交推送，commit 6e3dbde，APP_BUILD 43→44**，等 Codemagic 构建 + TestFlight 真机验证。

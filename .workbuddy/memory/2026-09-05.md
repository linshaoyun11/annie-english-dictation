## 🔴 重大发现：305 个 .mp3 其实是 WAV（占全库 34%）（00:20–00:40）

回答用户「为什么会有超过 48kbps 的文件」时挖出来的**真 bug**。

### 根因

有道 `dictvoice` 偶尔返回 **RIFF/WAV**，但 `Content-Type` 仍写 `audio/mpeg`。
旧生成脚本（`generate_audio.mjs` / `generate_audio_uk.mjs` / `generate_audio_editions.mjs`）
只校验 `buf.length >= 1000` 就 `writeFileSync(outPath, buf)` ⇒ **WAV 数据被写进 .mp3 文件**。
浏览器靠内容嗅探仍能播，所以一直没人发现。

实测复现（2026-09-05）：
```
"bridge"       type=2  200  ct=audio/mpeg  magic=RIFF  102094B
"cute"         type=2  200  ct=audio/mpeg  magic=RIFF  100566B
"environment"  type=1  200  ct=audio/mpeg  magic=RIFF  160328B
"hello"        type=1  200  ct=audio/mpeg  magic=ID3.  11565B   ← 同一个词另一口音就是 MP3
```

### 规模

| 真实格式 | 文件数 | 占用 |
|---|---|---|
| MP3(ID3) | 4420 | 56.7 MB |
| MP3(裸帧) | 958 | 13.5 MB |
| **WAV/PCM 伪装** | **305** | **36.4 MB（34.1%）** |

WAV 伪装文件参数：48000Hz / 16bit / mono（2 个是 16000Hz），即 768 kbps 原始 PCM。
单文件平均 120 KB，最大的 168 KB。全是**单词**（0/305 含空格）。
前缀分布 kb 104 / g 83 / ox 78 / ra 20 / wy 20；301 个在用，4 个孤儿。

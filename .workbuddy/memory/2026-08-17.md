## 英语听音拼写学习 APP（Web 版原型）

用户需求：按国内小学一年级到初中三年级（人教版）教学进度的英语学习 App。
核心交互已实现：
- 每个学习条目（单词/短语/句子）一个页面，上滑进入下一个
- 页面初始只显示发音波浪动画（无任何英文/音标/中文提示），循环朗读，间隔约 2 秒，输入不中断发音
- 波浪图标下方有"查看提示"按钮，点击后才显示音标和中文
- 拼写输入：每个字母下方黑色下划线，实时比对，正确变绿、错误变红；标点预填不需输入
- 进度持久化 localStorage，可按年级开始、清空进度

技术栈：Vite + React + TypeScript + Tailwind CSS v4，语音用 Web Speech API（speechSynthesis），打包产物在 dist/。

## 00:45 修复退出重进入发音错位 bug
- 根因：genRef 是 useRef，组件重新挂载后重置为 0。旧实例 resolveAudio 异步返回时 gen=1 恰好等于新实例 genRef=1，旧音频未被拦截，覆盖 audioRef 播放错误单词
- 修复：generation 计数器从 useRef 改为模块级 `let activeGen = 0`，不随组件卸载重置；新增 myGen ref 跟踪当前实例的 gen；speakWebSpeech/playOnce 也加 gen 检查
- 同时修复查看提示按钮抢焦点问题：按钮加 onMouseDown preventDefault，点击后输入框不失焦

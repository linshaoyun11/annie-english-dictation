## 第四轮：国家平台「只有三年级起点」的根因与影响

用户反馈：**「国家平台里所有版本的教材都是从三年级开始」**。

### 根因（政策级，是硬边界不是平台遗漏）

《义务教育课程方案(2022年版)》：**小学英语国家课程起始开设年级 = 三年级**；
一二年级不作统一开课要求，可开"英语预备类课程"，**教材由省级审定**，不得读写/纸笔考试。
（出处：泸县、安庆大观区、蒙阴县教体局 2026 年公开答复）

国家平台只收《国家课程教学用书目录》内教材 ⇒ **任何一年级起点教材都取不到**。
实证：dzkbw.com 一年级英语上册（五四制·牛津上海版）页面标注
「该书不在《2025年国家课程教学用书目录》，不是现行版本」；
青岛即墨/平度、德州齐河/庆云、烟台海阳 2025–2026 教科书目录里，
一二年级是「义教英语(一年级起点)」、三年级起是「(三年级起点)」——两套并行征订。

## 音频与 id 的关系（2026-09-04 查证，重要更正）

用户问"更新词库后音频对应关系会不会出错"。查证结论：

**✅ 不会出错。** `src/lib/audio.ts:96` = `manifest.get(text.trim().toLowerCase())`
⇒ **音频解析只按「文本」查 manifest，完全不碰 entry.id**。
链路：`文本 → manifest → id → audio/{id}.mp3`，manifest 的 value 与 mp3 文件名
是同一套 id，自洽。改词库（哪怕 G4-G9 全部 id 偏移）**音频零影响**。

⚠️ **MEMORY.md 旧记的"mk() 必须稳定否则 1061 个音频失配"是过度担心**，已在 MEMORY.md 更正。
那条警告只在"用 generate_audio 脚本新生成音频"层面部分成立（新文件按新 id 命名），
但对既有音频文件+manifest 无影响。

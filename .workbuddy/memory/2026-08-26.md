## 学习页默认键盘冷启动 BUG 修复
- 现象：APP 启动第一次进入学习页时，键盘偶尔不是英文小写全键盘（变成中文九宫格），手动切换成英文后每次都生效。怀疑与 APP 唤醒/启动时序有关。
- 根因：
  - React JSX 上设置 `inputMode="text"`，仅在 useEffect 中通过 `setAttribute("inputmode", "latin")` 强制改。
  - 冷启动时 iOS 评估键盘的时机在 React 渲染后立即（继承上一次的输入模式），useEffect 是异步的（在 paint 之后），改 "latin" 已晚。
  - visibilitychange 重建 input 时 iOS 已被切换到英文模式（用户手动切过），所以 setAttribute 生效。
- 修复（`src/components/SpellingInput.tsx`）：
  - 提取 `applyKeyboardAttributes(el)` 工具函数，统一封装 `autocapitalize=none` / `inputmode=latin` / `lang=en` / `pattern=[a-zA-Z]*` 等。
  - 把原 useEffect 升级为 useLayoutEffect（DOM 插入后立即同步执行，先于 iOS 评估键盘）。
  - 在 input 的 ref callback 中（commit 阶段同步，最早时机）立即调用 `applyKeyboardAttributes` 一次。
  - 移除 React JSX 上的 `inputMode="text"`（TypeScript 不支持 "latin" 且会被 ref callback 覆盖，徒增渲染开销）。
- 验证：tsc 通过。生产构建待跑；真机冷启动验证需要重新打包推 TestFlight。
- 当前状态：改动未 commit，与本次通关页改造一起推下一个 build。

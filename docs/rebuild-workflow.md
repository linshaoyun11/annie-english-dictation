# 重建工作流（外研新标准 G1G2 + 沪教牛津整线）

> 2026-09-08 起。用户已承诺拍图后即可重建。

## 工具脚本

| 文件 | 用途 |
|---|---|
| `scripts/intake_curriculum.mjs` | 智能录入器（接受 stdin 词条 → 输出可贴入的 TS 代码） |

## 用户操作流程

### 步骤 1：拍照

每册拍 4 组页（按顺序）：
1. **CONTENTS** — 目录（确认 Unit/Module 顺序）
2. **Vocabulary in Each Unit** — 每单元词表
3. **Vocabulary A-Z** — 词汇表（字母序）
4. **Useful Expressions** — 常用表达

### 步骤 2：iPad 复制文本

iOS/iPadOS 自带**实况文本**：
- 打开照片 → 双指放大锁定词 → 长按 → "实况文本"或"复制文本" → 粘贴到任何 App
- 一次最多 30-50 词，建议按页复制

也可以直接在 App 里用拍照后的"识别文字"：
- iPad 文件 → 长按图片 → "提取文字"

### 步骤 3：粘贴格式

每行一个词条，4-5 列用 `|` 分隔：

```
# 例：waiyanshe 1A Module 1（Hello/你好）
1|1|hello|/həˈləʊ/|int. 喂；你好
1|1|hi|/haɪ/|int. 喂；你好
1|1|goodbye|/ˌɡʊdˈbaɪ/|int. 再见
1|1|bye|/baɪ/|int. 再见
1|1|good morning|/ˌɡʊd ˈmɔːnɪŋ/|早上好
1|2|stand|/stænd/|v. 站
...
```

- 第 1-2 列：`grade` + `unit`（位置编码，如 `1|3` = G1U3）
- 可选省略的 grade：留空时沿用上一行的 grade
- 第 3 列：英文（必填）
- 第 4 列：音标（可空）
- 第 5 列：中文释义（可空）

### 步骤 4：运行解析器

```bash
node scripts/intake_curriculum.mjs --curriculum wy --book "1A"
# 默认 --preview：只输出预览
# --apply：写到 scripts/_intake_wy_TIMESTAMP.ts
```

### 步骤 5：合并到数据文件

把输出的 `mk(...)` 行 复制到：
- **waiyanshe G1G2** → `src/data/waiyanshe.ts` 中相应 Unit 的 `entries:` 段（替换占位精简版）
- **oxford 整线** → `src/data/oxford.ts` 中相应 Unit 的 `entries:` 段

App 立即可见（Vite HMR 热更新）。

## 录入顺序建议

按"先小后大"原则（最大化快速进度可见）：

### 优先级 1：waiyanshe G1G2
| 册 | Unit 数 | 词条估计 | 累计进度 |
|---|---|---|---|
| 1A | 20 | ~200 | 20% |
| 1B | 20 | ~200 | 40% |
| 2A | 20 | ~250 | 65% |
| 2B | 20 | ~350 | 100% |

### 优先级 2：oxford G1-G9
每册 12 Unit × 12 词 ≈ 150 词，按 G1 → G9 顺序录入。

## 重启会话时

把这次解析好的 `_intake_wy_TIMESTAMP.ts` 内容继续粘贴即可，id 体系自动续编。
不会撞号（`mkWithPrefix` 内部用 prefix 独立计数器）。

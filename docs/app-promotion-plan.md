> 适用前提：个人开发者账号 · **完全免费、无内购、无广告** · 中国区为主 · 零预算起步

## 0. 先看结论

**当前状态**（2026-09-25 实测）：已上架、可下载；搜索索引**只收录全名**（`安妮英语听写` 排第 1 位），`英语听写` / `单词听写` / `英语默写` / `人教版英语` 等通用词**均无排名**。

**三条主线，按性价比排序：**

| 优先级 | 主线 | 成本 | 见效 |
|---|---|---|---|
| **① 先修产品** | 补「评分引导 + 分享入口 + 语言声明 + 缺失截图」 | ¥0 | 立刻，是所有推广的地基 |
| **② Apple 生态内免费渠道** | ASO 关键词 + 精选提名 + App 内活动 | ¥0 | 2-8 周 |
| **③ 内容平台（家长在哪去哪）** | 小红书 / 微信生态 / 知乎 / B站 | ¥0 | 4-12 周 |

**付费渠道排在最后**，而且对个人开发者大多走不通（见 §5）。

## 1. ⚠️ 前提：四个产品短板（不修，推广就是漏水的桶）

老规矩：**先量再改**。以下四条都是实测确认的，不是推测。

| # | 短板 | 实测依据 | 对推广的伤害 | 修复成本 |
|---|---|---|---|---|
| 1 | **无评分引导** | 全项目 `grep requestReview / SKStoreReviewController` 无命中；商店页显示无评分 | 评分同时是**搜索排名因子**和**转化因子**。0 评分的新 App 在通用词上排不上去，商店页访客也更容易划走 | 需改代码，随 v1.0.1 发 |
| 2 | **无分享入口** | 全项目 `grep navigator.share` 无命中 | 免费 App 唯一的**零成本裂变路径**被堵死。家长想推荐给同学家长，只能口头说名字 | 需改代码，随 v1.0.1 发 |
| 3 | **商店页「语言」显示 EN 英语** | 商店页实测：`语言 → EN 英语`；iTunes API `languageCodesISO2A = ["EN"]` | 中文界面却标「英语」，家长会怀疑「这 App 是不是英文的」。且 App 语言会影响 Apple 语义模型对**中文关键词**的处理 | 改 Info.plist 本地化声明（CI 脚本，见 §1.1） |
| 4 | **线上截图缺 1 张** | 线上 7 张，本地 8 张，缺 `02-learn.png`（听写输入界面，最能说明产品价值的一张） | 商店页是推广的**终点**，所有渠道的流量都汇到这里。首页到收口环节掉链子 | 重新上传，¥0 |

### 1.1 语言声明怎么改

`ios/` 目录不在仓库（CI 现场生成），所以只能改构建脚本。`codemagic.yaml` 里「设置版本号、竖屏方向与状态栏」那一步已有 `PlistBuddy` 注入的先例，可照样式追加：

```bash
# 声明本地化为简体中文（解决商店页「语言」栏显示 EN 的问题）
/usr/libexec/PlistBuddy -c "Add :CFBundleLocalizations array" "$PLIST" 2>/dev/null || true
/usr/libexec/PlistBuddy -c "Add :CFBundleLocalizations:0 string zh-Hans" "$PLIST" 2>/dev/null || true
/usr/libexec/PlistBuddy -c "Set :CFBundleDevelopmentRegion zh-Hans" "$PLIST" 2>/dev/null || true
```

> ⚠️ 改完必须实测：`npx tsc -b --noEmit`（Capacitor 配置层）+ 打一个包看商店页「语言」栏是否变成「简体中文」。**不要只改不验** —— 这是本项目的既有教训。

### 1.2 这样修，比什么都划算

以上四条**全部合并进 v1.0.1 一次发出**。理由：每发一次版本都要重走审核（首发 8-14 天），而且**改元数据会重置搜索索引窗口**（ASO 社区口径 1-3 周）。分次改等于反复把排名推倒重来。

—— 而**现在正是索引重置成本最低的时刻**：通用词还没建立排名，重置等于没有损失。

## 2. 主战场：Apple 生态内的免费渠道

这三件事的共同点：**不花一分钱、绝大多数开发者不知道或懒得做**。

### 2.1 ASO 关键词体系（最高优先，地基）

依据：业界通行口径是**约 65% 的 App 发现来自商店搜索**。这是唯一"不花钱、不依赖算法推荐、持续吃自然流量"的渠道。

| 动作 | 怎么做 |
|---|---|
| 补副标题 | 见 `docs/appstore-aso-copy.md` §5（名称/副标题**必须发新版本**才能改） |
| 补关键词 | 同上。⚠️ 先核对 ASC 里现有内容 —— 若上一版删掉了「人教版/外研社」而副标题也没带，这两个高价值词在三个字段中可能全部缺席 |
| **截图文案参与索引** | iOS 的**截图注音文字自 2025-06 起被 OCR 索引** ⇒ 8 张截图每张都应带上目标关键词（如「人教版三年级起点」「英音美音」）。**这是免费的额外关键词位** |
| 营销 URL | 当前为空，可填隐私政策/支持页或后续的介绍页 |

### 2.2 精选提名（Featuring Nominations）—— 最被低估的零成本渠道

**入口**：App Store Connect → App → 侧边栏「精选」→「提名」→「创建提名」

| 项 | 规则（Apple 官方） |
|---|---|
| 所需职能 | 账户持有人 / 管理 / App 管理 / 营销（**你作为账号本人天然满足**） |
| 类型 | 新内容 / App 增强 / **App 发布**（你这次属「App 增强」或可再报一次发布） |
| 提前量 | Apple 建议**至少提前 3 周**；想跨多个版面被考虑，官方建议最长提前 3 个月 |
| 可附材料 | 最多 5 个补充 URL（演示视频、设计稿、TestFlight 链接），最多 10 个关联 App |
| 成本 | ¥0 |

**它值得做的理由**：这是**编辑人工挑选**的通道，与算法搜索排名相互独立 —— 提名不影响关键词排名，但一旦入选就是 Today / Apps 标签页的免费大版面。

**本项目的胜算在哪**：教育类是 Apple 编辑的常设主题，且这个 App 有一个**很难得的故事**——个人开发者为孩子做的、完全免费无广告无收集。教育 + 隐私友好 + 无障碍（若补上）正好压在 Apple 的编辑偏好上。

**时间点**：教学节奏是教育类最强的曝光抓手。现在（9 月底）可瞄准 **11 月期中 / 1 月期末 / 2 月开学**，按提前 3 周算，**10 月中之前就该交第一个提名**。

### 2.3 App 内活动（In-App Events）—— 免费且能反哺关键词

同样是免费入口，且比提名更容易落地。**关键在于：活动的标题与描述本身参与关键词索引** —— 相当于在 100 字符关键词之外又拿到一块索引空间。

| 项 | 规格 |
|---|---|
| 字段 | 标题 ≤30 字符、短描述 ≤50、长描述 ≤120、卡片图 2960×1320（可见安全区更窄） |
| 类型 | 挑战 / 竞赛 / 实时活动 / 重大更新 / 新赛季 / 首映 / 特别活动（共 7 类） |
| 展示位置 | 搜索结果、Today 标签、Apps 标签、产品页 Events 区、个性化推荐 |
| 频率 | Apple 建议**每年 2-4 次**（过度使用会稀释效果） |
| 审核 | 1-3 个工作日，可在开始前 14 天提交 |
| 成本 | ¥0 |

**本项目可直接用的活动**：
- 「期末听写冲刺 21 天」（挑战类）—— 标题本身就是搜索短语
- 「新教材上线：科普仁爱版」（新内容类）

⚠️ 活动必须是**真实有时效的**，常驻型「活动」会被拒。

### 2.4 评分积累

评分同时影响排名与转化。**但只能走正路**：

- ✅ 在 App 里做**恰当的时机引导**（完成一个单元/连续学习后弹系统评分框）
- ✅ 让真实用户（家人、朋友、家长群）用起来后自然留评
- ❌ **绝不买评、刷评、互评** —— Apple 有识别机制，轻则评分清零，重则下架；小红书的算法同样能识别

目标：**先拿到 10-20 条真实好评**。新 App 从 0 到 10 条评分，对通用词排名的推动是可见的。

## 3. 内容平台：家长在哪，你去哪

### 3.1 小红书（首推）

**为什么**：K12 家长的第一聚集地，且教育类内容的**搜索流量**在增长（有行业数据称教育行业搜索年增长约 399%）—— 家长是"主动搜"而不是"被动刷"。

**可行做法**：
- **账号定位**：「一个给孩子做英语听写工具的家长」比「官方账号」更吃得开
- **内容形态**：家长视角的真实使用场景（"娃的听写我不用逐字念了"）> 功能罗列
- **布局关键词**：标题/正文自然包含「英语听写」「单词默写」「人教版三年级起点」等家长实际会搜的词
- **新号先养**：注册当天就发营销内容会被判营销号 —— 先完成自然互动建立权重，再逐步发内容

**⚠️ 四条红线（违一条轻则限流、重则封号）**：

| 红线 | 说明 |
|---|---|
| **站外导流** | 2026 年平台已升级语义追踪，微信/手机号/「私我」/变形字/图片水印/二维码**全部纳入检测**。⇒ **笔记里只能引导「App Store 搜索：安妮英语听写」，绝不能出现任何联系方式** |
| **效果承诺** | 教育类不得出现「提分」「逆袭」「保过」「暴涨」等表述（也涉及未成年人隐私）。客观描述使用过程，让家长自己判断 |
| **AI 内容标注** | 使用 AI 辅助写文案/生成配图必须勾选「AI 辅助创作」标签，否则单篇限流 7 天、账号扣分 |
| **数据造假** | 买赞/买粉/刷收藏 = 永久限流 |

> 👉 正因为不能导流，**ASO 必须先做好**：小红书的流量最终要靠用户自己"去 App Store 搜"来承接。搜不到 = 白推。

### 3.2 微信生态（转化率最高）

微信是**唯一可以自由导流**的阵地（站内不构成违规导流）：

| 载体 | 用法 |
|---|---|
| **家长群 / 家委会** | 最直接的冷启动。让老师或熟悉的家长转发一句「我家孩子在用，免费没广告」 |
| **公众号** | 写干货（如「小学英语听写在家怎么练」），文末放商店链接/小程序码 |
| **视频号** | 短视频演示，可直接跳转/引导，比小红书自由得多 |

### 3.3 其他内容平台

| 平台 | 定位 | 要点 |
|---|---|---|
| **知乎** | 长尾搜索 | 回答「小学生英语听写用什么软件」「有什么免费无广告的背单词 App」类问题，自然提及。适合长期沉淀，不用天天更新 |
| **抖音** | 短视频 | 15-30 秒演示「一键听写」；家长刷视频时长可观 |
| **B站** | 中长视频 | 有行业观察称 3 分钟以上中长视频曝光权重更高。适合讲「为什么我给孩子做了个 App」 |

### 3.4 科技媒体 / 社区（一次性爆发 + 长尾）

这是**独立开发者最吃香的一类渠道**，因为这个 App 有天然的好故事。

| 渠道 | 说明 |
|---|---|
| **少数派** | 独立开发者友好，Matrix 社区可投稿。用「我为什么做了一个完全免费的英语听写 App」这种角度 |
| **小众软件 / 异次元软件** | 只推荐免费好用的工具，与本 App 的「无广告无内购」高度契合 |
| **AppSo / 爱范儿** | 科技媒体推荐位 |
| **V2EX / 即刻** | 开发者社区，分享产品迭代故事 |
| **Product Hunt** | 若考虑海外（当前 App 界面为中文，价值有限） |

**投递要点**：媒体的选品标准不是"功能多"，而是**"有没有一个值得写的点"**。「完全免费 + 无广告 + 无注册 + 不收集任何数据 + 6 套教材 + 全离线」这一组特性，在当下是有新闻性的。

## 5. 付费渠道：先想清楚，再决定

### 5.1 ⚠️ 一个现实约束：个人开发者大多投不了

| 渠道 | 个人开发者能否使用 |
|---|---|
| **Apple Search Ads** | ✅ **可以**。用 Apple ID 直接开通，无需企业主体 —— 这是唯一对个人友好的付费渠道 |
| 小红书（聚光/蒲公英） | ❌ 商业投放通常要求企业号/行业资质，教育类还是定向邀约类目 |
| 抖音（千川） | ❌ 同类约束 |

⇒ **对你而言，付费渠道实际只有 Apple Search Ads 一条路。**

### 5.2 Apple Search Ads（唯一对个人可行的付费渠道）

**它是什么**：用户在 App Store 搜索时，你的 App 出现在结果**最顶部**（带「广告」标记）。

**中国区可用**，且建议按下述结构搭（Apple 官方推荐的四类分法）：

| 广告组 | 关键词 | 特点 |
|---|---|---|
| **品牌词** | `安妮英语听写` 及变体 | 便宜，**守护自己的流量**。虽已排第 1，但可防竞品截流 |
| **品类词** | `英语听写` `单词默写` | 最相关、也最贵的一块。**你的目标用户就在这搜** |
| **竞品词** | 已知竞品名 | 抢比价用户 |
| **发现词** | 宽泛匹配 + Search Match | 小预算试，从「搜索词」报告里挖新词 |

**出价逻辑**（Apple 的公开口径）：

```
最高 CPT ≈ 目标 CPA × 点击到安装的转化率
```

**⚠️ 但对免费 App 要有清醒判断**：你没有内购、没有订阅，**投放是纯支出，没有直接回收**。所以：
- 建议**先只投品牌词 + 少量品类词**，日预算设到很低（如 ¥30-50），跑 1-2 周看数据
- 把 ASA 当作**"买初始用户和评分"的手段**来评估，而不是当作 ROI 生意
- 2026 年 Apple 已把「最大化转化次数」（设目标 CPA）开放给所有广告主，先用它比手工出价省事
- **务必设硬预算上限** —— Apple 超支是允许的，实际月花费≈日预算×30.4

### 5.3 如果将来要正经投小红书

需要企业主体（或找服务商代投）。**现阶段不必考虑**，先靠 §3.1 的免费内容把口碑做起来；有数据了再谈投放，转化会好得多。

## 6. 最独特的传播资产（所有内容的统一话术）

无论投哪个渠道，**对外只说一组特性** —— 这是本 App 相对竞品的真实差异点，也是最难被抄的部分：

> **6 套主流教材同步（人教版 / 外研社 / 沪教牛津 / 科普仁爱版，含一年级起点与三年级起点）**
> **654 个单元 · 6108 个词条 · 美音 + 英音双口音**
> **完全免费 · 无广告 · 无内购 · 无需注册 · 不收集任何个人信息 · 全部内容离线可用**

对比一下市面现状：主流背单词/听写类 App 大多有免费额度上限或订阅墙（墨墨需购买单词上限、小易英语听写月费、快乐听写错题本需订阅）。**"零收费 + 零收集 + 零联网"是可以直接讲出来的差异。**

⚠️ 但注意措辞合规：
- 用「**免费的英语学习工具**」，不用「培训班 / 课程 / 提分」类表述（涉学科培训监管）
- 不提「保过」「逆袭」「提分 XX 分」
- 数字口径统一用**去重后的「654 个单元、5000+ 词条」**（脚本 `scripts/aso_stats.mjs` 可重算），**不要**用各线累加的 18001

## 7. 落地节奏（30 天）

| 时间 | 动作 | 验收 |
|---|---|---|
| **第 1 周** | 修四个短板：评分引导、分享入口、语言声明、补传 `02-learn.png`；核对 ASC 关键词实际内容 | `tsc` 通过；本地截图 8/8；商店页「语言」变中文 |
| **第 1 周末** | 攒齐 v1.0.1 全部元数据改动（副标题 + 关键词 + 截图文案），触发构建 | Codemagic 出包、ASC 收到新构建 |
| **第 2 周** | 提交 v1.0.1 审核；同时**提交第一个精选提名**（瞄准 11 月期中） | 提名状态为 Submitted |
| **第 2-3 周** | 小红书账号开始养号（先自然互动，再发 1-2 篇真实使用笔记）；知乎写 1-2 个回答 | 内容发出且未被限流 |
| **第 3-4 周** | 找 10-20 个真实用户用起来；微信生态（家长群/朋友圈）自然扩散 | 拿到首批真实评分 |
| **第 2 个月** | 发布第一个 App 内活动；小预算试 Apple Search Ads（仅品牌词+品类词） | 活动过审上线；ASA 有花费数据 |
| **第 2-3 个月** | 投科技媒体（少数派/小众软件）；根据 ASA 搜索词报告反哺关键词 | 至少一家媒体收录；关键词列表更新 |

**每两周跑一次**（判断有没有长进）：

```bash
node scripts/verify_live.mjs cn --search 英语听写 --search 单词听写 --search 英语默写
```

看两个数：**通用词有没有进前 50**、**有没有评分出现**。这两个数动起来，才说明推广产生了效果。

## 8. 明确不要做的事

| 别做 | 原因 |
|---|---|
| **刷评 / 买量 / 互评** | Apple 与小红书都有识别机制，代价是下架或永久限流 |
| **在小红书留联系方式或二维码** | 2026 年平台语义追踪已覆盖变形字与水印，直接封号 |
| **"为了保险"在分级问卷里答高** | 分级填高会进家长控制过滤名单，直接减少可下载人群 |
| **分次改元数据** | 每次改都重置搜索索引窗口（1-3 周），等于反复推倒重来 |
| **盲目申请加急审核** | Apple 会记录申请历史，透支额度；只在线上版本出严重 bug 时用 |
| **在小红书提「提分/保过/逆袭」** | 违反教育类内容规范，且涉未成年人效果承诺 |
